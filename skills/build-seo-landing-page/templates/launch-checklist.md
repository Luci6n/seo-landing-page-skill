# Launch Checklist

## Before Deploy

- [ ] Title is specific.
- [ ] Meta description is natural.
- [ ] Canonical URL is correct.
- [ ] Open Graph metadata is correct.
- [ ] Twitter metadata is correct.
- [ ] Favicon files exist.
- [ ] Manifest exists.
- [ ] Robots, sitemap, manifest, `llms.txt`, and common icon files checked.
- [ ] AI-crawler access in `robots.txt` matches what the site owner agreed to.
- [ ] No unreplaced template placeholders remain.
- [ ] Structured data validates.
- [ ] No fake review/rating schema added.
- [ ] Sitemap exists.
- [ ] Robots file points to sitemap.
- [ ] Important content is visible in HTML.
- [ ] Mobile layout checked.
- [ ] Text does not overflow on mobile.
- [ ] Images have useful `alt`, `width`, and `height` where practical.
- [ ] CTA links tested.
- [ ] External links use `rel="noopener"` when opening new tabs.
- [ ] Animations do not move layout on page load.
- [ ] Reduced-motion behavior checked.

## After Deploy

- [ ] Live URL loads.
- [ ] SSL is active.
- [ ] Sitemap URL loads.
- [ ] Robots URL loads.
- [ ] Canonical URL points to the final live URL.
- [ ] Structured data URLs point to the final live URL.
- [ ] Social preview image loads.
- [ ] Rich Results Test checked.
- [ ] Lighthouse or PageSpeed checked.
- [ ] Search Console property added.
- [ ] Sitemap submitted.
- [ ] URL inspected.
- [ ] `llms.txt` links point to the final live URL.
- [ ] Google Business Profile updated, if local business.
- [ ] Custom domain added to business/social profiles, if available.

## Later

- [ ] Custom domain added.
- [ ] Real photos added.
- [ ] Reviews requested from real customers.
- [ ] Core Web Vitals monitored.
- [ ] Search Console indexing checked again after crawl.
- [ ] Generative AI performance report checked in Search Console, if available.
